Razborov's flag algebras \cite{Razborov2007} is a powerful framework for
reasoning about asymptotic densities in combinatorial structures, especially
in extremal graph theory. Since its introduction, it has been successfully
applied to solve several longstanding open problems, such as the minimum triangle density
problem under a fixed edge density \cite{Razborov2008} and the minimum pentagon density problem under the same constraint \hy{Citation}. Moreover, the flag algebra method has been
implemented in computer programs, enabling researchers to obtain numerical
bounds for various extremal problems, some of which resolve open conjectures \hy{Citation}.

This is a yet another survey on Razborov's flag algebras, which is intended to be more accessible to
readers with a background in theoretical computer science, particularly those
interested in programming languages and formal methods. While most articles on flag algebras emphasise
the algebraic aspect of the flag-algebra framework, we focus on its logic aspect and present the syntax, semantics, and reasoning principles of flag algebras in a manner similar to formal logic systems.

Throughout the paper, we refer to finite simple graphs simply as graphs. For a graph $G$, we let $V(G)$ 
and $E(G)$ be the vertex set and the edge set of $G$, respectively, and write $v(G)$ and $e(G)$ 
for their cardinalities, i.e., the number of vertices and that of edges. Also, for a set $U \subseteq V(G)$, we define $G[U]$ to be the subgraph of $G$ induced by $U$.

where $U$ is a uniformly random $v(H)$-subset of $V(G)$.

A sequence of graphs $(G_n)_{n \in \mathbb{N}}$ is \emph{increasing} if $v(G_n) < v(G_{n+1})$ for all $n \in \mathbb{N}$, and it is \emph{convergent} if the sequence is increasing and the limit $\lim_{n \to \infty} p(H, G_n)$ exists for every graph $H$. 
A function $\phi$ from the set of all graphs to $[0,1]$ is a \emph{limiting density map} if there exists a convergent sequence of graphs $(G_n)_{n \in \mathbb{N}}$ such that $\phi(H) = \lim_{n \to \infty} p(H, G_n)$ for every graph $H$. Let 
$\Phi$ be the set of all limiting density maps.
